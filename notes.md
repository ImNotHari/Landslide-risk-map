# Project Progress Notes

The project began with the establishment of a GitHub repository titled "Landslide risk map," complete with initial git configuration, a `.gitignore` tailored for Python data science, and an initial README. A sample Jupyter Notebook demonstrating a conceptual machine learning pipeline was fleshed out into a 30-cell comprehensive geospatial framework, though it was later reset to an empty state at user request. The system was also configured via workspace rules to enforce a strict no-emoji communication policy.

Focus then shifted to processing the NASA Global Landslide Catalog (GLC) for the "AI-Based Geospatial Feature Extraction and Landslide Risk Prediction System." Step 1 involved performing a read-only initial inspection of the dataset using a generated notebook and summary script, revealing significant missing data in event times, injury metrics, and storm names. In Step 2, a robust Python cleaning pipeline was constructed to address these anomalies without blindly dropping rows. It imputed numerical casualties with zeroes, standardized categorical terminology by grouping ambiguous labels into "unknown", dropped severely sparse columns, and generated a clean dataset in `data/processed/`.

In Step 3, the ML prediction dataset was meticulously designed by focusing on the Kerala and Western Ghats region. The dataset isolated 193 positive, rainfall-triggered landslide events. To provide contrast, a 1:3 class balance was achieved by synthetically generating 579 negative samples. These negative samples were strictly constrained to land masses using the `global-land-mask` library, enforced a 5.0 km spatial buffer from any known positive event to prevent false negatives, and were assigned dates mirroring the positive event distribution to mitigate temporal bias.

Finally, in Step 4, an automated terrain feature extraction module was developed. The script utilized the NASA Shuttle Radar Topography Mission (SRTM) dataset via `srtm.py` to fetch 90-meter resolution elevation grids. For every coordinate in the ML dataset, it extracted central elevation and calculated localized slope and aspect using Horn's differential grid calculus. The terrain-augmented dataset was saved, and diagnostic visualizations were produced to validate the topographic relationships against landslide occurrences.
